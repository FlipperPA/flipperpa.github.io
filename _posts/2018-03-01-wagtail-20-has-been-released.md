[Wagtail 2.0 has been released today](https://wagtail.io/blog/wagtail-2/), and it is fairly jam packed with features. [The software that powers this blog, Peregrine](https://github.com/flipperpa/peregrine), is built on top of the Wagtail CMS and Django. I've found it is best to stand on the shoulders of giants!

Peregrine has been using Wagtail 2.0 since it was in alpha. Now that Wagtail 2.0 has been released, we will be releasing Peregrine in a few weeks.

Wagtail 2.0 contains a slew of new features, including Django 2.0 compatibility and a fresh new text editor for content creators. I know my team at work is pretty excited about the new editor - it really is magnificent.

Check it out if you haven't: all the beautiful details are here: <https://wagtail.io/blog/wagtail-2/>
